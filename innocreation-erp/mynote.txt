အခု App နဲ့ MySQL ချိတ်ကြမယ်။

၁။ .env ဖိုင်ဖန်တီးပါ

VS Code ဖိုင်အသစ်ကို .env လို့ နာမည်ပြောင်းပါ။

အထဲမှာ ဒီလိုဖြည့်ပါ။
PORT=3000
DB_HOST=127.0.0.1
DB_PORT=3306
DB_NAME=innocreation_erp
DB_USER=innocreation_app
DB_PASSWORD="YOUR_DB_PASSWORD_HERE"
SESSION_SECRET=
NODE_ENV=development

DB_PASSWORD မှာ စောစောက SQL ထဲမှာ သတ်မှတ်ထားတဲ့ Password ထည့်ပါ။


၂။ Session Secret ထုတ်ပါ

Terminal မှာ ဒီ Command Run ပါ။
node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"

ထွက်လာတဲ့ စာသားရှည်ကို Copy လုပ်ပြီး .env ထဲက SESSION_SECRET= နောက်မှာ Paste လုပ်ပါ။ ပြီးရင် Ctrl + S နဲ့ Save ပါ။



၃။ Users Table ဖန်တီးပါ
npm.cmd run setup

အောင်မြင်ရင် ဒီစာပေါ်ပါမယ်။
Users table ready. Next: npm run create-admin



၄။ Login အကောင့်ဖန်တီးပါ
npm.cmd run create-admin

မေးလာတဲ့ Username၊ Display name၊ Password နဲ့ Confirm password ကို ဖြည့်ပါ။ 
Password ကို အနည်းဆုံး ၁၂ လုံး ထားပါ။ ရိုက်တဲ့ Password က Terminal မှာ မြင်ရပါတယ်။



၅။ Website Run ပါ
npm.cmd start

Browser မှာ http://localhost:3000 ဖွင့်ပြီး ခုနက ဖန်တီးထားတဲ့အကောင့်နဲ့ Login ဝင်ပါ။

Server ကို ရပ်ချင်ရင် VS Code Terminal ထဲမှာ—
Ctrl + C

နောက်တစ်ခါ ပြန်ဖွင့်ချင်ရင်
npm.cmd start

၄။ လက်ရှိ Database ကို Export လုပ်ပါ

MySQL Workbench မှာ—
1. လက်ရှိ Local MySQL Connection ကိုဖွင့်ပါ။
2. Server → Data Export ကိုနှိပ်ပါ။
3. ERP Database ကိုရွေးပြီး Table အားလုံး ရွေးပါ။
4. Dump Structure and Data ကိုရွေးပါ။
5. Export to Self-Contained File ကိုရွေးပါ။
6. Include Create Schema ကို အမှန်မခြစ်ပါနဲ့။
7. Start Export နှိပ်ပါ။
ရလာတဲ့ .sql ဖိုင်ကို Backup အဖြစ် သိမ်းထားပါ။


-----------------------------------------------------------------

၅။ Hostinger Database ထဲ Import လုပ်ပါ

Database ဖန်တီးပြီးသားဆိုရင်—
1. Databases → Management ကိုဝင်ပါ။
2. u506347531_innocreation Database ဘေးက phpMyAdmin ကိုဖွင့်ပါ။
3. အဲဒီ Database ကိုရွေးပါ။
4. Import → Choose File မှာ .sql ဖိုင်ကိုရွေးပါ။
5. Import / Go နှိပ်ပါ။
Export ထဲမှာ CREATE DATABASE သို့မဟုတ် Local Database ကိုညွှန်းတဲ့ USE innocreation_erp; ပါနေရင် 
Hostinger Database နာမည်နဲ့ မကိုက်နိုင်လို့ Import မလုပ်ခင် ပြင်ရပါမယ်။ Import က လက်ရှိ Hostinger Database ကို ရွေးပြီးလုပ်တာ ဖြစ်ရပါမယ်။
